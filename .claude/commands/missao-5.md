# Missão 5 · Claude Code no seu sistema

Siga o CLAUDE.md. Fale em português simples, um passo por vez, e espere o aluno responder "feito" quando o passo depender dele. Texto extra que o aluno escreveu depois do comando: $ARGUMENTS

## Objetivo
Você e o aluno se conhecerem, e o perfil dele ficar guardado no repositório para guiar as próximas missões.

## Passos
1. Apresente-se em 3 linhas: você está ligado ao repositório dele, consegue ler e mudar o código, testar e publicar (push → a Vercel publica sozinha). Ele decide, você executa.
2. Mostre em tópicos curtos o que já vem pronto (leia o README.md): Visão geral, Contas a pagar, Enviar, Patrimônio, Configurações, segurança.
3. Entrevista (no máximo 5 perguntas por vez; use o que ele já escreveu em $ARGUMENTS, por exemplo as "MINHAS PARTICULARIDADES" copiadas da página do prompt mestre):
   - Quem vai usar (só ele, casal, família, empresa/MEI)?
   - Quantos cartões e como recebe as faturas (e-mail, app, PDF com senha)? Sem números de cartão.
   - Contas fixas, assinaturas e parcelamentos principais (só os tipos, sem valores).
   - Objetivos (organizar, quitar dívidas, reserva, viagem).
   - Celular iPhone ou Android; nível com tecnologia de 0 a 5; quanto pode gastar por mês para rodar.
4. Escreva PERFIL.md na raiz: módulos que ele vai usar, módulos para depois, custos esperados (Claude Pro que ele já tem + API da Anthropic com limite baixo; Vercel, Supabase e GitHub grátis). Nada de CPF, número de cartão, valores reais ou e-mails.
5. Mostre o PERFIL.md, ajuste até ele aprovar, faça commit ("Perfil do meu sistema") e push.

## Para fechar
Resuma em 3 linhas o que foi feito e diga ao aluno o que mandar para a Lia: uma frase dizendo que o Claude Code está ligado e o PERFIL.md foi salvo.
