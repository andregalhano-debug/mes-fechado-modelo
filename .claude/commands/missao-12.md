# Missão 12 · Primeira fatura lida pela IA

Siga o CLAUDE.md. Fale em português simples, um passo por vez, e espere o aluno responder "feito" quando o passo depender dele. Texto extra que o aluno escreveu depois do comando: $ARGUMENTS

## Objetivo
Enviar um PDF de fatura, conferir e confirmar.

## Passos
1. Explique o caminho da fatura no código: envio → leitura pela IA → tela de revisão → gravação.
2. Diga o que conferir na revisão (datas, valores, parcelas, compras repetidas).
3. Se a leitura errar, ajude a descobrir se foi a fatura ou o sistema, sem ele colar dados pessoais. Se for o sistema, proponha a correção no código.
Para testar sem dados reais: fatura fictícia em https://mes-fechado-ten.vercel.app/exemplos/fatura-exemplo-mes1.pdf

## Para fechar
