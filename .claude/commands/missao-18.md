# Missão 18 · Do seu jeito

Siga o CLAUDE.md. Fale em português simples, um passo por vez, e espere o aluno responder "feito" quando o passo depender dele. Texto extra que o aluno escreveu depois do comando: $ARGUMENTS

## Objetivo
Uma melhoria só dele, construída com você, e o fechamento do primeiro mês.

## Passos
1. Pergunte o que ele quer (ou use $ARGUMENTS). Sugira 3 ideias a partir do PERFIL.md se ele não souber.
2. Plano em 3 a 5 linhas → aprovação → partes pequenas, cada uma com como testar.
3. testar:banco, build, commit, push. Confira com ele no site publicado.
4. Atualize o PERFIL.md com a lista de pendências e ideias para depois.

## Para fechar
Resuma em 3 linhas o que foi feito e diga ao aluno o que mandar para a Lia: o endereço do sistema e uma frase dizendo o que foi personalizado.
